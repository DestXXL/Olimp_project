# Трамплин - Карьерная платформа для IT-специалистов

Полнофункциональная карьерная платформа для студентов, выпускников, работодателей и карьерных центров вузов в IT-сфере.

## Стек технологий

- **Next.js 14+** - App Router, Server Actions
- **TypeScript** - типизация
- **PostgreSQL** - база данных
- **Prisma ORM** - работа с БД
- **NextAuth.js** - аутентификация
- **Tailwind CSS** - стилизация
- **shadcn/ui** - UI компоненты
- **Leaflet + OpenStreetMap** - карты
- **Docker Compose** - контейнеризация

## Быстрый старт

### 1. Запуск базы данных

```bash
docker-compose up -d
```

### 2. Установка зависимостей

```bash
npm install
```

### 3. Настройка окружения

```bash
cp .env.example .env
```

Отредактируйте `.env` файл при необходимости.

### 4. Инициализация базы данных

```bash
# Генерация Prisma клиента
npm run db:generate

# Выполнение миграций
npm run db:migrate

# Заполнение тестовыми данными
npm run db:seed
```

### 5. Запуск приложения

```bash
# Режим разработки
npm run dev

# Или сборка и запуск продакшена
npm run build
npm start
```

Приложение будет доступно по адресу: http://localhost:3000

## Функциональность

### Роли пользователей

- **Гость** - просмотр каталога, избранное в localStorage
- **Соискатель** - профиль, отклики, контакты, избранное
- **Работодатель** - компания, публикация возможностей, отклики
- **Куратор** - модерация, верификация работодателей
- **Администратор** - управление кураторами, системные настройки

### Основные сущности

- **Возможности** - стажировки, вакансии, менторство, карьерные события
- **Теги** - технологии, навыки, направления
- **Отклики** - заявки на возможности
- **Контакты** - профессиональная сеть
- **Модерация** - очередь на проверку

## Команды

```bash
# Разработка
npm run dev              # Запуск dev сервера
npm run build            # Сборка приложения
npm run start            # Запуск продакшена
npm run lint             # Проверка линтером
npm run type-check       # Проверка типов

# База данных
npm run db:generate      # Генерация Prisma клиента
npm run db:migrate       # Выполнение миграций
npm run db:seed          # Заполнение тестовыми данными
npm run db:studio        # Prisma Studio
npm run db:reset         # Сброс и пересоздание БД
```
